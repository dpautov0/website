ECE 340 · Exam 1 · FRONT$kT = 0.0259$ eV · $q = 1.6\times10^{-19}$ C · Si $n_i = 1.5\times10^{10}\,\text{cm}^{-3}$, $E_g = 1.12$ eV · cm, not m

1 · Carriers at equilibrium

  • $n_0p_0 = n_i^2$ always at equilibrium. Majority = doping; minority $= n_i^2/\text{majority}$.
  • $n_0 = n_ie^{(E_F - E_i)/kT}$, $p_0 = n_ie^{(E_i - E_F)/kT}$.
  • $E_F - E_i = kT\ln\frac{n_0}{n_i}$ (ln). ×10 in $n_0$ → $E_F$ up 0.0596 eV.
  • $n_0 = N_ce^{-(E_c - E_F)/kT}$, $p_0 = N_ve^{-(E_F - E_v)/kT}$. Si: $N_c = 2.8\times10^{19}$, $N_v = 1.04\times10^{19}$.
  • $n_i = \sqrt{N_cN_v}e^{-E_g/2kT}$; $N_c \propto T^{3/2}$. Valid if $E_F$ is >3kT from both band edges.
  • Donors: col. V (P, As, Sb). Acceptors: col. III (B, Al, Ga). All ionized at 300 K.

2 · Fermi function

  • $f(E) = \frac{1}{1 + e^{(E - E_F)/kT}}$: probability a state is full. Empty: $1 - f$.
  • $f(E_F) = \frac12$ at every $T$. $T = 0$: step.
  • Symmetric: full at $E_F + \Delta$ = empty at $E_F - \Delta$.
  • $E - E_F > 3kT$: $f \approx e^{-(E - E_F)/kT}$.

3 · Compensation, neutrality, temperature

  • $p_0 + N_d^+ = n_0 + N_a^-$ → $n_0 = \frac{N_d - N_a}{2} + \sqrt{\left(\frac{N_d - N_a}{2}\right)^2 + n_i^2}$.
  • $|N_d - N_a| \gg n_i$: $n_0 = N_d - N_a$. Else (Ge, hot Si, $N_d \approx N_a$) use the root.
  • $\frac{n_i(T_2)}{n_i(T_1)} = \left(\frac{T_2}{T_1}\right)^{3/2}e^{-\frac{E_g}{2k}\left(\frac1{T_2} - \frac1{T_1}\right)}$, $k = 8.62\times10^{-5}$ eV/K.
  • Freeze-out (cold, $n_0 < N_d$) → extrinsic ($n_0 = N_d$) → intrinsic (hot, $n_0 \to n_i$).

4 · Drift, conductivity, resistance

  • $v_d = \mu\mathscr{E}$; $J = q(n\mu_n + p\mu_p)\mathscr{E} = \sigma\mathscr{E}$; $\rho = 1/\sigma$; $R = \rho L/A$.
  • Both carriers' currents point along $\mathscr{E}$: they add.
  • $\frac1\mu = \frac1{\mu_L} + \frac1{\mu_I}$; $\mu_L \propto T^{-3/2}$; $\mu_I \propto T^{3/2}/(N_d + N_a)$.
  • Light doping: $\mu$ falls with $T$. Heavy: rises then falls. More doping (even compensating): lower $\mu$.
  • High field: $v_d$ saturates ≈ $10^7$ cm/s. Hall: $p_0 = \frac{I_xB_z}{qtV_H}$.
  • Si: $\mu_n = 1350$, $\mu_p = 480$ cm²/V·s (light doping).

5 · Diffusion, total current, built-in field

  • $J_n = q\mu_nn\mathscr{E} + qD_n\frac{dn}{dx}$; $J_p = q\mu_pp\mathscr{E} - qD_p\frac{dp}{dx}$.
  • Electrons diffuse down the gradient, so their current points up it.
  • Einstein: $D = \frac{kT}{q}\mu$. Si: $D_n = 35$, $D_p = 12.4$ cm²/s.
  • Equilibrium: $E_F$ flat, $J_n = J_p = 0$. Graded: $\mathscr{E} = -\frac{kT}{q}\frac1n\frac{dn}{dx}$; $N_d = N_0e^{-x/L}$ → $\mathscr{E} = +\frac{kT}{qL}$ (to light side); $N_a$: $-\frac{kT}{qL}$ (to heavy side).
  • $\mathscr{E} = \frac1q\frac{dE_c}{dx}$ (field points uphill in $E_c$). Contact: $qV_0 = kT\ln\frac{N_aN_d}{n_i^2}$.

6 · Excess carriers, quasi-Fermi levels

  • Low level ($\delta n \ll n_0 + p_0$): $\delta n = \Delta n\,e^{-t/\tau}$, $\tau_n = \frac{1}{\alpha_r(n_0 + p_0)} \approx \frac{1}{\alpha_rp_0}$ (p-type).
  • High level: $\delta n = \frac{\Delta n}{1 + \alpha_r\Delta n\,t}$, halves at $t = \frac{1}{\alpha_r\Delta n}$.
  • Steady light: $\delta n = g_{op}\tau_n$, $\delta p = g_{op}\tau_p$. $g(T) = \alpha_rn_i^2$.
  • $n = n_ie^{(F_n - E_i)/kT}$, $p = n_ie^{(E_i - F_p)/kT}$. Use $n_0 + \delta n$! Minority QFL moves.
  • $\Delta\sigma = qg_{op}(\tau_n\mu_n + \tau_p\mu_p)$. $np = n_i^2$ is equilibrium only.

7 · Continuity, diffusion length

  • $\frac{\partial p}{\partial t} = -\frac1q\frac{\partial J_p}{\partial x} - \frac{\delta p}{\tau_p}$; $\frac{\partial n}{\partial t} = +\frac1q\frac{\partial J_n}{\partial x} - \frac{\delta n}{\tau_n}$.
  • No field: $\frac{\partial\delta p}{\partial t} = D_p\frac{\partial^2\delta p}{\partial x^2} - \frac{\delta p}{\tau_p}$. Steady: $L_p = \sqrt{D_p\tau_p}$.
  • Long bar: $\delta p = \Delta p\,e^{-x/L_p}$, $J_p = \frac{qD_p}{L_p}\Delta p\,e^{-x/L_p}$.
  • Short bar ($W \ll L$): linear, $J_p = qD_p\Delta p/W$.

8 · Optical absorption

  • $E\,[\text{eV}] = 1.24/\lambda\,[\mu\text{m}]$. Absorbed only if $h\nu \ge E_g$.
  • $I = I_0e^{-\alpha x}$; absorbed $1 - e^{-\alpha d}$. Heat fraction $\frac{h\nu - E_g}{h\nu}$. Photons/s $= P/h\nu$ (J).

9 · Bands, effective mass

  • $m^* = \hbar^2/\frac{d^2E}{dk^2}$; $E = E_c + Ak^2$ → $m^* = \frac{\hbar^2}{2A}$ (J, m).
  • Direct (GaAs): emits light. Indirect (Si, Ge): needs phonon.
  • Metal: partly filled band. Semi: $E_g \sim 1$ eV. Insulator: $\gtrsim 5$ eV.
  • Gaps: Si 1.12, GaAs 1.43, Ge 0.67 eV.

10 · Crystals

  • Atoms/cell: sc 1, bcc 2, fcc 4, diamond 8. $N = \#/a^3$. Si $a = 5.43$ Å → $5.00\times10^{22}$.
  • Miller: intercepts → reciprocals → integers. $[hkl] \perp (hkl)$ (cubic). $(100)$ fcc/diamond: $2/a^2$.

11 · Traps

  • μm → cm: ×$10^{-4}$. Å → cm: ×$10^{-8}$. Use ln, not log.
  • Minority is $n_i^2/N$, not $n_i$. Lifetime uses the majority concentration.
  • $L = \sqrt{D\tau}$. Sign of $J_n^{\text{diff}}$: $+qD_n\,dn/dx$.

Ex 1 · Doped Si: $n_0$, $p_0$, $E_F$

Si, $N_d = 10^{16}$, 300 K.

  • $n_0 = 10^{16}$; $p_0 = \frac{2.25\times10^{20}}{10^{16}} = 2.25\times10^4\,\text{cm}^{-3}$.
  • $E_F - E_i = 0.0259\ln\frac{10^{16}}{1.5\times10^{10}} = 0.347$ eV.
  • $E_c - E_F = 0.0259\ln\frac{2.8\times10^{19}}{10^{16}} = 0.206$ eV.

Ex 2 · Fermi probability, $n_0$ from $N_c$

Si, $E_F$ 0.20 eV below $E_c$.

  • $f(E_c + kT) = \frac{1}{1 + e^{0.2259/0.0259}} = 1.63\times10^{-4}$.
  • $n_0 = 2.8\times10^{19}e^{-7.72} = 1.24\times10^{16}$.
  • $p_0 = 1.04\times10^{19}e^{-0.92/0.0259} = 3.89\times10^3$.

Ex 3 · Compensated Ge ($n_i$ not negligible)

$N_d = 3\times10^{13}$, $N_a = 10^{13}$, $n_i = 2.5\times10^{13}$.

  • $n_0 = 10^{13} + \sqrt{10^{26} + 6.25\times10^{26}} = 3.69\times10^{13}$.
  • $p_0 = n_i^2/n_0 = 1.69\times10^{13}$. Check: $p_0 + N_d = n_0 + N_a$ ✓.
  • Shortcut $N_d - N_a$ would be 46% low.

Ex 4 · Hot Si

$n_i(600) = 1.5\times10^{10}\cdot2^{3/2}e^{\frac{1.12}{2(8.62\times10^{-5})}\cdot\frac{1}{600}} = 2.14\times10^{15}$.

  • $N_d = 10^{15}$: $n_0 = 5\times10^{14} + \sqrt{2.5\times10^{29} + 4.57\times10^{30}} = 2.70\times10^{15}$.

Ex 5 · Bar resistance

n-Si $10^{16}$, $\mu_n = 1350$, $L = 1$ mm, $A = 100\times10\,\mu$m², 5 V.

  • $\sigma = qN_d\mu_n = 2.16\,(\Omega\text{cm})^{-1}$, $\rho = 0.463\,\Omega$cm.
  • $A = 10^{-5}$ cm²: $R = \frac{0.463(0.1)}{10^{-5}} = 4.63$ kΩ, $I = 1.08$ mA.
  • $J = 108$ A/cm², $v_d = 1350(50) = 6.75\times10^4$ cm/s.

Ex 6 · Mobility at another $T$

300 K: $\mu_L = 1500$, $\mu_I = 3000$ → $\mu = 1000$.

  • 400 K: $\mu_L = 1500(4/3)^{-3/2} = 974$, $\mu_I = 3000(4/3)^{3/2} = 4620$.
  • $\mu = (1/974 + 1/4620)^{-1} = 805$ cm²/V·s.

Ex 7 · Two regions in contact

$N_a = 10^{16}$ meets $N_d = 10^{17}$.

  • n: $E_F - E_i = 0.0259\ln(6.67\times10^6) = 0.407$; p: $E_i - E_F = 0.347$ eV.
  • $E_F$ lines up; bands step $qV_0 = 0.754$ eV.

Ex 8 · Graded doping

$N_d = 10^{17}e^{-x/L}$, $L = 0.5\,\mu$m, $\mu_n = 1000$.

  • $\mathscr{E} = \frac{kT}{qL} = \frac{0.0259}{0.5\times10^{-4}} = 518$ V/cm, $+x$.
  • $D_n = 25.9$. At 0: drift $+8.29\times10^3$, diffusion $-8.29\times10^3$ A/cm²: sum 0.

Ex 9 · Light into thin GaAs

0.5 μm, $\alpha = 3\times10^4$, 10 mW at 2.00 eV, $E_g = 1.43$.

  • $\alpha d = 1.5$: $P_{\text{abs}} = 10(1 - e^{-1.5}) = 7.77$ mW.
  • Heat $= 7.77\cdot\frac{0.57}{2.00} = 2.21$ mW. Photons $\frac{7.77\times10^{-3}}{3.2\times10^{-19}} = 2.43\times10^{16}$/s.

Ex 10 · Pulse decay, low level

p-GaAs $10^{17}$, $\alpha_r = 7.2\times10^{-10}$, $\Delta n = 10^{14}$.

  • $\tau_n = \frac{1}{\alpha_rp_0} = 13.9$ ns. At 20 ns: $10^{14}e^{-20/13.9} = 2.37\times10^{13}$.
  • To $10^{12}$: $t = 13.9\ln100 = 64.0$ ns.

Ex 11 · High level

$n_0 + p_0 \approx 0$, $\alpha_r = 10^{-10}$, $\Delta n = 10^{17}$.

  • $\delta n(100\,\text{ns}) = \frac{10^{17}}{1 + (10^{-10})(10^{17})(10^{-7})} = 5.00\times10^{16}$.

Ex 12 · Quasi-Fermi levels, photoconductivity

n-Si $10^{15}$, $g_{op} = 10^{19}$, $\tau = 2\,\mu$s.

  • $\delta p = g_{op}\tau = 2.00\times10^{13}$ (low level).
  • $F_n - E_i = 0.0259\ln(6.80\times10^4) = 0.288$; $E_i - F_p = 0.0259\ln1333 = 0.186$ eV.
  • $\Delta\sigma = q\,\delta p(\mu_n + \mu_p) = 5.86\times10^{-3}\,(\Omega\text{cm})^{-1}$.

Ex 13 · Steady-state injection

Holes into n-Si: $\Delta p = 10^{14}$, $\mu_p = 480$, $\tau_p = 1\,\mu$s.

  • $D_p = 12.4$, $L_p = \sqrt{12.4\times10^{-6}} = 35.3\,\mu$m.
  • $\delta p(50\,\mu\text{m}) = 10^{14}e^{-50/35.3} = 2.42\times10^{13}$.
  • $J_p(0) = \frac{qD_p\Delta p}{L_p} = 56.4$ mA/cm², toward $+x$.

Ex 14 · Drift + diffusion components

$p = 10^{16}e^{-x/2\mu\text{m}}$, $\mathscr{E} = +20$ V/cm, $\mu_p = 480$; at $x = 0$:

  • Drift $q\mu_pp\mathscr{E} = 15.4$ A/cm².
  • Diffusion $-qD_p\frac{dp}{dx} = +\frac{qD_pp}{L} = 99.5$ A/cm². Total $114.8 \to 115$ A/cm².

Ex 15 · Atoms per cm³ and per cm²

  • Si: $8/(5.43\times10^{-8})^3 = 5.00\times10^{22}$ cm⁻³; $\rho_m = \frac{NM}{N_A} = 2.33$ g/cm³.
  • $(100)$: $2/a^2 = 6.78\times10^{14}$ cm⁻².
